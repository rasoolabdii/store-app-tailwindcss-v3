Project Store with Tailwind Css v.3

📦 Installation

Clone the repository and install the dependencies:

npm install

You need to install the Live Server extension in VS Code.

▶️ Run the Project

Start the development server with:

npm run dev

The server will be available at:

http://127.0.0.1:5500/public

📚 API Documentation

Interactive API documentation is available :

URL UI:

http://127.0.0.1:5500/public

http://127.0.0.1:5500/public/cart.html

http://127.0.0.1:5500/public/singleProduct.html
